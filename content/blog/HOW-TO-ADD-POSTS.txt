HOW TO ADD A BLOG POST
======================

1. Copy the template file:
   content/post-template.md

   Paste it into this folder (content/blog/) and rename it.
   Example: my-post-title.md

   Use lowercase letters, numbers, and hyphens in the filename.
   That filename becomes the URL: /blog/my-post-title

2. Edit the top section (between the --- lines):
   - title:   The headline shown on the site
   - date:    Use YYYY-MM-DD format
   - excerpt: Short summary for the blog list page
   - draft:   Set to false when ready to publish (template starts as true)

3. Replace the placeholder content below the header.
   Keep the headings and formatting you need; delete the rest.

4. Publish:
   npm run build:pages
   Then commit and push to GitHub (same as updating the rest of the site).

Images: place files in public/images/ and reference them as /images/filename.jpg
